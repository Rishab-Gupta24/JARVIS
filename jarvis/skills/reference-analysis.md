Studying a reference game ("make a game like X"):
- Learn from public descriptions only: wiki pages, reviews, guides, store descriptions. Never download,
  unpack, decompile or copy the real game's files, code, art, sounds or text.
- Write down what makes it play the way it does: camera/view, core loop, controls, moves and mechanics,
  progression (unlocks, upgrades, currencies), match structure, difficulty curve, game feel.
- Separate MECHANICS (fine to use: genre conventions, rules, structure) from IDENTITY (never copy: name,
  characters, story, setting, levels, art style, music, logos, distinctive UI).
- End with "Our original take": a new title, new characters and setting, and a visual style that is
  clearly different from the reference's signature look, keeping the mechanics that make it fun.
