A good PRD for a small game:
- One-sentence pitch: genre, core action, what makes it fun ("a side-view duel where timing a block opens a counter").
- The core loop in 3-5 steps (e.g. pick fighter -> fight 3 rounds -> earn coins -> upgrade -> next opponent).
- Controls: every action and its key (and touch button for web games).
- Features ranked: MUST for the first playable version, SHOULD after. Keep MUST small enough to finish.
- Scenes (menu, play, pause, results, shop...) and what moves between them.
- Original identity: its own title, characters, setting and art style. Never reuse a reference game's name,
  characters, story, levels, art or music; borrowing mechanics and genre conventions is fine.
- Done means: it starts, every scene is reachable, the core loop can be played start to finish, tests pass.
